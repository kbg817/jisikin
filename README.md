# 답변·댓글 센터

네이버 지식iN · 유튜브 · 쓰레드에 올라오는 글 중 **내 제품·서비스와 관련된 글만 자동으로 모아서**,
답변·댓글을 달 만한 순서대로 보여주는 프로그램입니다. 제목을 클릭하면 바로 그 글이 열려 답변·댓글을 달 수 있습니다.
(유튜브는 조회수가 많은 영상, 즉 사람들이 많이 보는 영상부터 보여줍니다.)

- **제품별 키워드**: 신의소리(신점·타로, 유튜브는 재회·연애 주파수 영상도), 명연당(사주), 명운연구소(작명·개명), 닥사렌 모각크림(모공각화증·건선), 음파쑥쑥(키 성장), 치디핏(치질·항문외과), 세이프맘 탄소매트(탄소매트·전기장판·온수매트)
- **카테고리 자동 분류**: 제품 키워드가 없어도 "헤어진 전남친이랑 다시 만날 수 있을까요?" 같은 질문을 `재회운` 으로 분류해서 모아줍니다.
- **추천순 정렬**: 관련도 + 답변 수가 적을수록 + 최근 질문일수록 위로. `답변 0` 질문은 초록색으로 표시됩니다.
- **할 일 관리**: 클릭한 질문은 흐리게 표시되고, `답변완료` / `제외` 를 누르면 목록에서 빠집니다. 같은 질문을 두 번 보지 않습니다.
- **자동 수집**: 켜두면 10분마다(설정 가능) 새 질문을 가져옵니다.
- **상위노출 글**: "인천 건선" 같은 검색어로 네이버에서 지금 위에 뜨는 지식iN 글(옛날 글 포함)과 순위·조회수를 추적합니다.
- **검색어 자동 생성**: 메인 키워드(예: 건선)만 넣으면 자동완성·지역 조합·AI·월간 검색수로 세부 검색어를 만들어 줍니다.
- **작업 결과**: `답변완료`/`댓글완료` 한 글을 매일 아침 6시(`track_check_hour`)에 다시 열어, 내 답변·댓글이 아직 보이는지 확인합니다. 지식iN 은 채택 여부·상위노출 순위, 유튜브는 인기 댓글 순위·좋아요까지. 어떤 게 내 글인지는 [완료] 때 저장된 글 내용으로 찾습니다 (쓰레드는 Meta 검수 전이라 확인하지 않음).
- **유튜브 · 쓰레드**: 제품 이름이나 "모공각화증" 같은 말이 들어간 최신 영상·쓰레드 글을 찾아 제품별로 분류합니다. 댓글을 달고 `✓ 댓글완료` 를 누르면 답변 실적에 같이 잡힙니다.
- **여러 명이 함께 (서버)**: 서버에 올리면 직원이 어디서든 로그인해서 작업하고, 누가 몇 건 답변했는지 기록됩니다.
- **AI 답변 초안 (선택)**: Claude API 키가 있으면 제품별 답변 가이드에 맞춘 초안을 만들어 줍니다. 확인·수정 후 직접 붙여넣는 방식입니다.
  사주(명연당)·작명(명운연구소) 초안은 명연당 서버의 만세력·이름 판정으로 계산한 값을 씁니다 (5-1 참고).

## 0. 서버에 올리기 — 직원과 함께 쓰기 (Render, 월 약 1만 원)

PC 를 켜둘 필요 없이 24시간 수집하고, 사장님과 직원이 각자 인터넷 주소로 접속합니다.
이 저장소에 서버 설정(`render.yaml`, `Dockerfile`)이 들어 있어서 몇 번 클릭하면 됩니다.

1. <https://render.com> 에서 **GitHub 계정으로 가입** (Sign up with GitHub)
2. 오른쪽 위 **New +** → **Blueprint** → GitHub 저장소 **`kbg817/jisikin`** 선택
   (목록에 없으면 "Configure account" 에서 이 저장소 접근을 허용)
3. Blueprint 이름은 아무거나 (예: jisikin). 아래에 **`JISIKIN_ADMIN_PASSWORD`** 입력칸이 나오면
   **관리자 비밀번호**를 정해서 넣습니다. (영문+숫자+기호 10자 이상 권장)
4. **Apply** (또는 Deploy Blueprint) → 결제 카드 등록
   - 요금: Starter 서버 $7 + 저장 디스크 1GB $0.25 ≈ **월 1만 원** (싱가포르 지역)
5. 5~10분 뒤 서비스 화면 위쪽에 **`https://jisikin-xxxx.onrender.com`** 주소가 생깁니다. 접속해서
   아이디 **`admin`** / 3번에서 정한 비밀번호로 로그인
6. **[설정] → API 키**: 네이버 검색 API 키 붙여넣기 (아래 2번 참고)
7. **[설정] → 직원 계정**: 직원 이름·아이디·비밀번호를 만들고, 직원에게 **주소 + 아이디 + 비밀번호**를 전달
8. **[설정] → [연결 점검]**: 서버에서 네이버가 잘 읽히는지 확인. ⚠️ 가 나오면 결과를 복사해서 Claude 에게 보내주세요.

알아둘 점
- 설정·API 키·수집한 질문은 서버의 저장 디스크(`/app/data`)에 보관되어, 프로그램을 업데이트해도 유지됩니다.
- 이 저장소에 코드가 올라오면 Render 가 **자동으로 새 버전을 배포**합니다. (1~3분간 잠깐 접속이 안 될 수 있음)
- 서버는 데이터센터(싱가포르)에서 네이버에 접속합니다. 네이버가 데이터센터 접속을 더 자주 막을 수 있으니
  [연결 점검]과 [설정] → 최근 수집 기록의 오류를 가끔 확인하세요.
- 직원은 질문 목록·상위노출 글·답변완료 표시·AI 초안만 쓸 수 있고, **설정·검색어 관리·답변 예시는 관리자만** 볼 수 있습니다.
- 다른 직원이 이미 열어본 글에는 "○○ 확인 중" 표시가 떠서 같은 질문에 두 명이 답하는 것을 막아줍니다.
- 관리자 비밀번호를 바꾸려면 Render 서비스 → **Environment** → `JISIKIN_ADMIN_PASSWORD` 수정 → 저장 (자동 재시작)

### 업무 데스크와 연동 (선택)

사내 업무 대시보드(업무 데스크, `kbg817/seeding`)와 연결하면, 업무 데스크 홈에 **답변할 질문 수·직원별 오늘 답변 수**가 보이고
업무 데스크에서 **[열기]를 누르면 따로 로그인하지 않고** 들어옵니다. 직원 계정은 업무 데스크에서만 관리합니다.

1. 비밀번호 생성기로 40자 정도의 긴 문자열을 하나 만듭니다 (채팅·메신저로 보내지 마세요).
2. Render 의 **jisikin** 서비스 → **Environment** → `JISIKIN_LINK_SECRET` 에 그 값을 넣고 저장
3. Render 의 **work-desk** 서비스 → **Environment** → `TOOL_LINK_SECRET` 에 **같은 값**을 넣고 저장
4. 업무 데스크 **설정 → 연결된 도구**에서 답변·댓글 센터의 **숫자·로그인 연동**을 켭니다.

- 업무 데스크 아이디가 답변 센터 직원 아이디와 같으면 기존 답변 실적이 그대로 이어집니다. (예: 둘 다 `jieun`)
- 업무 데스크에서 직원을 **사용 중지**하면 답변 센터에서도 바로 막힙니다.
- 업무 데스크 관리자는 답변 센터의 관리자(`admin`)로 들어옵니다.

## 1. PC 에서 시작하기 (Windows 기준, 약 10분)

1. **내려받기**: GitHub 저장소 페이지 → 브랜치가 `claude/naver-knowledge-collector-ug8qeu` 인지 확인 →
   초록색 **Code** → **Download ZIP** → 압축 풀기
2. **실행**: 폴더의 **`start.bat` 더블클릭**
   - Python 이 없으면 자동으로 설치합니다. (설치 허용 창이 뜨면 '예')
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**
   - 처음엔 1~3분 걸리고, 끝나면 브라우저에 대시보드(`http://127.0.0.1:5000`)가 열립니다.
3. **네이버 API 키 넣기**: 대시보드 **[설정] → API 키** 칸에 붙여넣고 [키 저장]. 발급 방법도 그 화면에 있습니다. (아래 2번)
4. **[연결 점검]** 버튼을 눌러 결과를 확인합니다. ⚠️ 가 나오면 [결과 복사]해서 Claude 에게 보내주세요.

> 검은 창을 닫거나 PC가 꺼지면 수집이 멈춥니다. 쓰는 동안 창을 켜두세요.

Mac / Linux 는 터미널에서 `./start.sh` (Python 3.10 이상 필요). 직접 실행하려면:

```bash
python -m venv .venv
.venv\Scripts\activate        # Mac/Linux: source .venv/bin/activate
pip install -r requirements.txt
python -m jisikin             # 대시보드 + 자동 수집
```

## 2. 네이버 검색 API 키 발급 (강력 권장, 무료)

키가 없어도 동작하지만(지식iN 검색 화면을 직접 읽는 **웹 모드**), 네이버 화면이 바뀌면 깨질 수 있고 느립니다.
공식 API 는 하루 25,000회까지 무료이고 안정적입니다.

> 2026년 7월 31일부터 네이버 개발자센터의 검색 API 신규 발급이 종료되고, **네이버클라우드 NAVER API HUB** 로 옮겨졌습니다.
> 검색 API 는 여전히 하루 25,000회까지 무료입니다. 예전에 개발자센터에서 받은 키도 그대로 넣으면 됩니다 (프로그램이 자동으로 구분).

1. <https://www.ncloud.com> 회원가입·로그인 (결제수단 등록을 요구할 수 있습니다)
2. **콘솔** → **All Services** → **Application Services** → **NAVER API HUB** → **이용 신청**
3. 왼쪽 **Application** 메뉴 → **[Application 등록]** → 사용할 API 에서 **검색** 선택 → **[다음]** →
   Application 이름 입력 (예: 지식인수집기) → **[완료]**
4. 만든 Application 을 선택 → **API 관리** 아래 **[인증 정보]** → `Client ID`, `Client Secret` 복사
5. 대시보드 **[설정] → API 키** 의 네이버 Client ID / Client Secret 칸에 붙여넣고 **[키 저장]** → **[연결 점검]**

키는 프로그램의 `.env` 파일(서버에서는 저장 디스크)에만 저장되고, 저장하면 재시작 없이 바로 적용됩니다.

## 3. 키워드 · 카테고리 설정

대시보드 오른쪽 위 **[설정]** 에서 바로 고칠 수 있습니다 (파일로는 `config.yaml`).
저장하면 형식을 검사하고, 이미 모아둔 질문도 새 설정으로 **다시 분류**합니다.

```yaml
products:
  - id: sinui
    name: 신의소리
    keywords: [신점, 타로, 사주, 운세, 궁합]        # 들어가면 관련 질문 + 이 단어로 지식iN 검색
    exclude: [사주세요, 사줘, 사주고 싶]            # 이 표현은 가리고 판단 ("옷 사주세요" 무시)
    categories:
      - name: 재회운
        keywords: [재회, 헤어진, 전 남친, 연락 올까]  # 분류용 단어
        search: [재회운, 재회 가능성]                # 이 카테고리 질문을 찾기 위한 추가 검색어
    watch_urls: []                                  # 지식iN 분야 목록 주소 (선택)
    min_score: 2
    answer_guide: |                                 # AI 초안용 제품 설명
      신의소리는 신점·타로·사주 상담 사이트입니다...
```

**점수 규칙** (제품별로 계산, `min_score` 이상이면 수집)

| 어디에 있나 | 제품 키워드 | 카테고리 단어 |
|---|---|---|
| 제목 | 3점 | 2점 |
| 본문 | 2점 | 1점 |

→ 제품 키워드는 어디에 있든 수집, 카테고리 단어만 있는 질문은 **제목에 있을 때** 수집됩니다.

**띄어쓰기 규칙**: 키워드에 넣은 띄어쓰기는 있어도/없어도 찾습니다.
`키 크는 법` → "키크는법", "키 크는법", "키 크는 법" 모두 찾음. `건선` → "건선" 만 찾음 ("조건 선택" 같은 오탐 방지).

**제외어**
- `사주세요` : 그 표현만 가리고 판단합니다. "사주 봐주세요 (옷은 엄마가 사주세요)" 는 여전히 수집.
- `!주식` : 앞에 `!` 를 붙이면 그 단어가 있는 질문은 이 제품에서 아예 뺍니다.
- 정규식이 필요하면 `re:` 를 붙이세요. 예) `re:사주(?!세요|줘)`

**watch_urls (분야 감시)**: 지식iN에서 원하는 분야(예: 운세·사주, 피부과, 소아청소년과)의 질문 목록 페이지로 가서
주소창 URL 을 복사해 넣으면, 키워드 검색에 안 걸리는 새 질문도 그 분야에서 가져와 분류합니다.

**튜닝 팁**
- 대시보드에서 **[관련도 낮은 질문도]** 를 켜면, 점수가 모자라 빠진 질문이 흐리게 보입니다. 놓친 질문이 보이면 키워드를 추가하세요.
- 엉뚱한 질문이 들어오면 `exclude` 에 그 표현을 넣으세요.
- [설정] 화면의 **분류 테스트** 나 `python -m jisikin classify "질문 제목" "본문"` 으로 바로 확인할 수 있습니다.

## 4. 사용 흐름

1. 제품 탭(신의소리 / 명운연구소 / 닥사렌 / 음파쑥쑥) → 카테고리 칩(재회운, 아기 작명, 성장판·검사 …)으로 좁히기
2. 제목 클릭 → 지식iN 질문이 새 탭으로 열림 (목록에선 '열어봄'으로 흐리게 표시)
3. 답변을 달았으면 **✓ 답변완료**, 답하지 않을 질문은 **제외**
4. 상단의 "오늘 답변 N건"으로 하루 실적 확인

## 4-1. 상위노출 글 (검색 상위에 뜨는 지식iN 글)

**[상위노출 글]** 탭은 "인천 건선" 같은 검색어를 네이버에서 검색했을 때 **지금 위쪽에 노출되는 지식iN 글**을 모아 보여줍니다.
노출 중인 글은 옛날 글이어도 조회수가 계속 늘어나기 때문에, 여기에 답변을 달면 오래 읽힙니다.

![상위노출 글 화면 (예시 데이터)](docs/screenshot-exposure.png)

- 확인하는 곳 (설정 `exposure_sources`)
  - `pc` : 네이버 통합검색(PC) 결과에 나온 지식iN 글 순서
  - `mobile` : 네이버 통합검색(모바일) 결과 순서 — 실제 검색은 모바일이 대부분이라 중요
  - `kin` : 지식iN 탭 정확도순 상위
- 글마다 보여주는 것: 위치별 순위(▲▼ 변동, 새로 진입하면 NEW), 조회수, **하루 조회수 증가량**, 답변 수, 작성일
- 정렬: 검색어별로 가장 높은 순위 → 여러 곳에 노출된 글 → 하루 조회수가 많은 글 순
- 12시간마다 자동 확인 (`exposure_interval_hours`), **[지금 확인]** 으로 바로 확인
- 답변완료/제외는 '새 질문' 탭과 공유됩니다. 답변완료한 글도 흐리게 남아 있어 어떤 검색어를 챙겼는지 한눈에 보입니다.

### 검색어 자동 생성 — [검색어 관리] (관리자)

메인 키워드(예: **건선**)만 넣고 **[저장하고 자동 생성]** 을 누르면 세부 검색어를 만들어 켜 둡니다.
생성이 끝나면 상위노출 확인까지 이어서 실행하고, 이후 **일주일마다 자동으로 다시 생성**합니다.

- 메인 키워드 기본값은 설정의 `exposure.seeds` (예: 닥사렌 `[건선, 모공각화증]`)이며, 처음 실행할 때 자동으로 채워져 바로 생성됩니다.
  화면에서 바꾸거나 비우면 화면 값이 우선합니다.
- 검색광고 API 키를 나중에 넣으면, 키 없이 만들었던 목록을 월간 검색수 기준으로 **자동으로 한 번 다시 만듭니다.**
  화면의 "마지막 생성 … (사용: 자동완성 · 조합 · 검색광고)" 에서 실제로 쓴 출처를 확인할 수 있습니다.

| 후보를 찾는 곳 | 필요한 것 | 예 |
|---|---|---|
| 네이버 자동완성 (2단계) | 없음 | 건선 원인 → 건선 원인 스트레스 |
| 지역·의도 조합 | 없음 (지역은 설정의 `regions`) | 인천 건선, 건선 병원, 건선 추천 |
| AI 추천 | Claude API 키 | 건선 초기 증상, 건선에 좋은 음식 |
| **월간 검색수** | 네이버 검색광고 API 키 (무료) | 건선 PC 3,000 / 모바일 20,000 |

- 제품과 관련 없는 검색어(메인 키워드도 없고 제품 키워드·카테고리에도 안 걸리는 것)는 자동으로 뺍니다.
- 검색광고 API 키가 있으면 **실제 월간 검색수가 많은 순**, 없으면 자동완성 순서 등으로 추정한 점수 순입니다.
- 목록에서 체크를 끄거나 직접 추가한 검색어는 "고정"되어 다시 생성해도 그대로 유지됩니다.
- 표의 **지식iN 노출** 칸에 마지막 확인 때 지식iN 글이 몇 개 떴는지 나옵니다. "없음"이 계속되면 꺼도 됩니다.

설정 파일로 직접 넣을 수도 있습니다 (제품별, 항상 확인):

```yaml
    exposure:
      keywords: [건선 크림 추천, 모공각화증 크림 추천]   # 그대로 검색
      regions: [서울, 인천, 부천, 수원]                  # 지역 ×
      region_terms: [건선, 건선 피부과]                  # 단어 → '인천 건선', '인천 건선 피부과' ... 자동 생성
```

> 참고: 오래된 질문 중 일부는 질문이 마감되었거나 삭제되어 답변을 달 수 없을 수 있습니다. 그런 글은 **제외**를 눌러 넘기세요.

## 4-2. 유튜브 · 쓰레드

**[유튜브]**, **[쓰레드]** 탭은 제품별 `social.keywords` 로 최근 영상·글을 찾아 보여줍니다.
브랜드 이름으로 **내 제품 언급**을 찾고, "모공각화증" 같은 주제어로 **댓글 달 만한 영상**을 찾는 용도입니다.

```yaml
    social:
      keywords: [닥사렌, 모공각화증, 건선 관리]   # 비워두면 제품 이름으로 검색
```

- 찾은 글은 지식iN 과 같은 점수 규칙으로 분류합니다. `social.keywords` 에 넣은 말(브랜드명 등)도 제품 키워드로 칩니다.
  점수가 모자란 글은 **[관련도 낮은 글도]** 를 켜면 흐리게 보입니다.
- 추천순: 관련도 + 최근 영상일수록 + 조회수가 많을수록 + 댓글이 적을수록(내 댓글이 위에 보이기 쉬움) 위로.
- **[AI 댓글]**: Claude API 키가 있으면 짧은 댓글/답글 초안을 만듭니다. 말투 원칙은 `ai.social_guide`,
  제품 설명과 금지 표현은 제품의 `answer_guide` 를 따릅니다. **자동으로 올리지 않습니다.** 확인·수정 후 직접 다세요.
- 기본 6시간마다 자동으로 찾습니다 (`social_interval_hours`). 각 탭의 **[지금 찾기]** 로 바로 찾을 수 있습니다.

### 유튜브 API 키 (무료)
1. <https://console.cloud.google.com> 에서 프로젝트 만들기
2. **API 및 서비스 → 라이브러리** 에서 `YouTube Data API v3` → **사용**
3. **사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키** → 복사
4. 대시보드 **[설정] → API 키 → 유튜브 · 쓰레드** 에 붙여넣고 [키 저장]

무료 할당량은 하루 10,000 이고 검색어 1개에 약 101 을 씁니다.
하루 사용량 ≈ 검색어 수 × 101 × (24 ÷ `social_interval_hours`). 기본값(검색어 12개, 6시간)은 약 4,850 입니다.
`youtube_daily_units`(기본 9,000)에 닿으면 그날은 멈추고, 한국 시간 오후 5시쯤 할당량이 초기화되면 다시 찾습니다.

### 쓰레드 토큰 (선택)
1. <https://developers.facebook.com/apps> 에서 앱 만들기 → 사용 사례 **Threads API 액세스**
2. 권한에 `threads_basic`, `threads_keyword_search` 추가 → 내 쓰레드 계정을 테스터로 등록
3. 장기 액세스 토큰(60일) 발급 → **[설정] → API 키 → 유튜브 · 쓰레드** 에 붙여넣기

- 토큰은 프로그램이 **7일마다 자동으로 연장**합니다.
- ⚠️ Meta **앱 검수를 통과하기 전에는 내 계정 글만** 검색됩니다. 다른 사람 글을 찾으려면 `threads_keyword_search` 권한 검수가 필요합니다.
  그 전에는 [쓰레드] 탭의 **토큰 없이 직접 보기** 링크로 키워드별 최신 글을 쓰레드에서 바로 열 수 있습니다.
- 검색 한도는 24시간에 2,200회입니다.

## 5. AI 답변 초안 (선택)

[설정] → API 키의 **Claude API 키** 칸에 키를 넣으면 각 질문에 **[AI 초안]** 버튼이 생깁니다.
키는 <https://platform.claude.com> 에서 발급합니다 (claude.ai 구독과 별도로 크레딧 충전 필요).
초안은 `config.yaml` 의 `ai.common_guide`(공통 원칙)와 제품별 `answer_guide` 를 따릅니다.
**[복사하고 질문 열기]** 를 누르면 초안이 복사되고 질문 페이지가 열리니, 확인·수정 후 붙여넣으세요.

- **모델·비용**: 기본은 Claude Sonnet 5.5, 생각 깊이 `low` (초안 1건 약 $0.01~0.03). 버튼을 누를 때만 만들고,
  만든 초안은 저장되어 다시 봐도 추가 비용이 없습니다. 이번 달 사용액(추정)은 **[설정] → AI 사용량**에 나옵니다.
  비용은 Claude 구독(Pro·Max)과 별개로 Claude Console 의 API 크레딧에서 나가며, 월 한도는 Console 에서 설정합니다.
- **답변 예시 (관리자)**: 상단 **[답변 예시]** 에서 ⭐를 단 모범 답변(제품·채널마다 20개)을 AI 가 참고해 말투·구성·길이를 맞춥니다.
  직원이 초안을 고쳐서 올리고 **[✓ 답변완료]** 를 누르면 그 최종본이 '직원이 올린 답변'에 자동으로 쌓이니, 잘 쓴 것에 ⭐를 다세요.
  예전에 채택된 답변을 직접 붙여넣을 수도 있습니다. 같은 제품의 초안은 앞부분(가이드+예시)이 같아서 캐시로 싸게 처리됩니다.

### 5-1. 명연당 계산 연결 — 사주·작명 초안 정확도

AI 가 생년월일로 간지·대운을, 이름으로 획수·수리를 **머리로 계산하면 자주 틀립니다**.
`calc_tools` 를 넣은 제품(기본: 명연당 `[saju, name]`, 명운연구소 `[name, hanja, saju]`)은 지식iN 초안을 쓰기 전에
명연당 서버에 계산을 맡기고, 그 결과로만 씁니다. 명연당 손님 분석과 같은 계산입니다.

- 사주: 절기 기준 월주, 지방시(동경 127.5°)·서머타임, 한국천문연구원 음력·윤달, 오행·십성·십이운성·신살·귀인·대운·올해/내년 세운
- 이름: 글자별 한자·뜻·원획·자원오행, 발음오행·발음음양, 사격수리(81수)·수리오행·수리음양 / 음으로 인명용 한자 찾기
- 명연당 서버는 **계산만 하고 아무것도 저장하지 않습니다** (손님 기록·통계·광고 추적에 섞이지 않음).
- 생년월일·이름이 없는 일반 질문은 계산 없이 씁니다. 계산을 쓰는 초안은 생각 깊이를 `medium` 이상으로 올려
  AI 가 계산을 건너뛰지 않게 합니다 (초안 1건 약 $0.02~0.05).
- 연결이 끊기거나 열쇠가 틀리면 초안을 만들지 않고 이유를 보여줍니다 (짐작으로 쓴 초안이 나가지 않게).
  열쇠를 아직 안 넣었으면 계산 없이 쓰되, 간지·획수 같은 값은 단정하지 않게 합니다.
- 명운연구소 초안에는 명연당 이름이 나오지 않습니다 (계산 도구에 상호를 넣지 않음).

연결 방법 (한 번만):
1. **[설정] → API 키 → 명연당 계산 연결 → [새 열쇠 만들기] → [복사]**
2. GitHub `kbg817/myeongyeondang` → Settings → Secrets and variables → Actions → New repository secret,
   이름 `JISIKIN_CALC_KEY`, 값 붙여넣기
3. 그 저장소 **Actions → Ops - Set jisikin calc key (prod) → Run workflow** (action: `on`).
   마지막에 `계산 API: 켜짐` 이 나오면 됩니다. (명연당 API 가 10초 정도 다시 시작됩니다)
4. 여기 **[키 저장]** → **[연결 점검]** 에서 `[OK] 명연당 계산 … 연결됨 — 시험 사주 庚午 壬午 甲辰 己巳`

### 꼭 알아두세요
- **자동 등록 기능은 일부러 넣지 않았습니다.** 지식iN 에 프로그램으로 답변을 자동 등록하면 운영정책 위반으로
  아이디 이용 제한·답변 삭제 위험이 큽니다. 광고성 답변 신고도 많아서, 사람이 확인하고 올리는 방식이 오래 쓸 수 있습니다.
- **판매자·운영자로서 추천할 때는 관계를 밝히는 것이 원칙**입니다(공정위 추천·보증 심사지침). AI 초안에는 운영자 소개 문장과 링크를 넣지 않도록 해 두었으니, 필요하면 올릴 때 직접 덧붙이세요.
- **건강 관련 제품 표현 주의**: 화장품(모각크림)이 질병을 "치료/완치"한다거나, 성장 제품이 "키를 몇 cm 키운다"는 표현은
  화장품법·식품표시광고법 위반 소지가 있습니다. 기본 가이드에는 금지 표현을 따로 넣지 않았으니, 초안은 올리기 전에 항상 직접 확인하세요.

## 6. 명령어

```bash
python -m jisikin              # 대시보드 + 자동 수집 (= serve)
python -m jisikin serve --port 5001 --no-browser
python -m jisikin collect      # 한 번만 수집하고 상위 질문 출력
python -m jisikin check        # 설정 / API 키 / 네이버 연결 / 상세 페이지 읽기 점검
python -m jisikin classify "헤어진 남친 연락 올까요"   # 분류 테스트
```

## 7. 설정값 (settings)

| 항목 | 기본값 | 설명 |
|---|---|---|
| `interval_minutes` | 10 | 자동 수집 주기(분). 0이면 끔. 웹 모드는 최소 30분 |
| `results_per_keyword` | 50 | 검색어당 최신 질문 수 (API 최대 100, 웹 최대 30) |
| `source` | auto | `api` / `web` / `auto`(키 있으면 api) |
| `fetch_details` | true | 관련 질문의 상세 페이지에서 답변 수·작성일·내공·본문 읽기 |
| `max_details_per_run` | 40 | 한 번에 상세 페이지를 여는 최대 개수 |
| `request_delay_seconds` | 1.0 | 네이버 페이지 요청 간격 |
| `max_age_days` | 14 | 이보다 오래된 질문은 할 일 목록에서 숨김 |
| `keep_days` | 60 | 이보다 오래된 미처리 질문은 정리 (답변완료는 보관) |
| `exposure_interval_hours` | 12 | 상위노출 글 확인 주기(시간). 0이면 끔 |
| `exposure_top_n` | 5 | 검색어마다 상위 몇 개까지 볼지 |
| `exposure_sources` | [pc, mobile, kin] | 확인할 곳 |
| `social_interval_hours` | 6 | 유튜브·쓰레드 자동 수집 주기(시간). 0이면 끔 |
| `social_max_age_days` | 14 | 이보다 오래된 영상·글은 찾지 않고 할 일에서도 숨김 |
| `youtube_results` | 25 | 검색어당 영상 수 (최대 50) |
| `youtube_daily_units` | 9000 | 유튜브 API 하루 사용 상한 (무료 10,000) |
| `threads_results` | 50 | 검색어당 쓰레드 글 수 (최대 100) |

API 모드의 하루 호출 수 ≈ `검색어 수 × (1440 ÷ 수집 간격)` 입니다. 기본 설정(검색어 58개, 10분)은 약 8,400회로 한도(25,000회) 안입니다.
[설정] 화면에서 예상 호출 수를 확인할 수 있습니다.

## 8. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| "네이버 API 인증 실패" | [설정] → API 키를 다시 붙여넣기 (앞뒤 공백 주의), 애플리케이션에 `검색` API 추가 여부 |
| 웹 모드에서 결과 0건 | 네이버 화면 구조가 바뀌었을 수 있음 → API 키 사용 권장 |
| `답변 ?` 로만 표시 | 상세 페이지를 아직 못 읽음 → [설정] → [연결 점검] 결과를 Claude 에게 보내주세요 |
| "지식iN 이 요청을 거부했습니다(403/429)" | `interval_minutes`, `request_delay_seconds` 를 늘리세요 |
| 포트가 이미 사용 중 | 프로그램이 이미 켜져 있는지 확인, 또는 `port` 변경 |

## 9. 앞으로 (최종 목표: 자동 답변)

지금 구조는 **수집 → 분류 → 우선순위 → (AI 초안) → 사람이 등록 → 답변완료 기록** 입니다.
다음 단계로 이런 것들을 붙일 수 있습니다.

- **텔레그램/카카오 알림**: `답변 0` + 관련도 높은 새 질문이 오면 휴대폰으로 알림 (빨리 답할수록 채택 확률 ↑)
- **AI 분류 보강**: 키워드로 애매한 질문만 Claude 로 한 번 더 분류
- **성과 추적**: 답변완료한 질문이 채택되었는지 나중에 다시 확인해 제품·카테고리별 채택률 통계
- **답변 템플릿 라이브러리**: 카테고리별로 잘 된 답변을 저장해 초안 품질 향상
